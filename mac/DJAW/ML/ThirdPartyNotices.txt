DJAW uses the following machine-learning models (converted to Core ML):

1) Beat This! — beat and downbeat tracking
   F. Foscarin, J. Schlüter, G. Widmer, "Beat this! Accurate beat tracking without DBN postprocessing", ISMIR 2024.
   https://github.com/CPJKU/beat_this — model "final0"
   MIT License, Copyright (c) 2024 Institute of Computational Perception, JKU Linz, Austria

2) CUE-DETR — DJ cue point estimation
   G. Argüello, L. Lanzendörfer, R. Wattenhofer, "Cue Point Estimation using Object Detection", ISMIR 2024.
   https://github.com/ETH-DISCO/cue-detr — weights https://huggingface.co/disco-eth/cue-detr (license: MIT, per the model card)

3) Discogs-EffNet — music style (genre) classification, 400 Discogs styles
   P. Alonso-Jiménez, X. Serra, D. Bogdanov, "Music Representation Learning Based on Editorial Metadata from Discogs", ISMIR 2022.
   https://essentia.upf.edu/models.html — model "discogs-effnet-bsdynamic-1" (Music Technology Group, Universitat Pompeu Fabra)
   Classifier heads on the same embeddings (voice_instrumental, mood_party, mood_aggressive, danceability — discogs-effnet-1),
   bundled into the same Core ML model.
   License: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0) — non-commercial use only.
   https://creativecommons.org/licenses/by-nc-sa/4.0/

Auto-mix tendencies were calibrated with statistics from the Raveform dataset (CC BY 4.0):
   T. Kim, J. Kim, H. Kim, J. Nam, "Raveform: A Dataset of Metrical and Functional Structure Annotations for EDM Tracks in DJ Mixes", TISMIR 2026.

original TensorFlow graph), exported to Core ML. The model outputs the vocal ratio mask; DJAW keeps the
instrumental as the track minus the vocals.
