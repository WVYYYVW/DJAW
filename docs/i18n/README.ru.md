# DJAW

[日本語](../../README.md) | [English](README.en.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Italiano](README.it.md) | [Português](README.pt.md) | **Русский**

Редактор DJ-миксов в стиле DAW (не в реальном времени). Вы сводите треки с подсказками по тактам, рисуете движения фейдеров, EQ, эффектов и вокала и экспортируете микс. Работает в Windows и на Mac (Apple silicon).

- `src/` — приложение для Windows / Mac (Electron + TypeScript)
- `mac/` — прежняя версия для macOS (SwiftUI), исходный эталон поведения
- Подробности устройства → [`docs/PORTING.md`](PORTING.ru.md) (переводы в `docs/i18n/`)

Для личного использования (у некоторых встроенных моделей некоммерческие лицензии).

## Установка

Со страницы [Releases](https://github.com/WVYYYVW/DJAW/releases):
- **Windows**: `DJAW-Setup-x.y.z.exe`
- **Mac (Apple silicon)**: `DJAW-x.y.z-mac-arm64.dmg`

После установки DJAW сам обновляется до новых версий при запуске.

## Запуск из исходников

Нужны [Node.js](https://nodejs.org/) 22 или новее (LTS) и Git.

```bat
git clone https://github.com/WVYYYVW/DJAW.git
cd DJAW
npm install
npm start
```

- `npm start` … собирает и запускает приложение (для разработки).
- `npm run dist` … собирает установщик (`dist/`).
- `npm test` … тесты движка рендеринга (звук не воспроизводится).

Результаты анализа и аудиокэш хранятся в `%APPDATA%\DJAW` (на Mac — `~/Library/Application Support/DJAW`).

## Экран

Похож на Ableton Live.
- Вверху: имя файла, транспорт, время, BPM и привязка (по центру окна), визуал, инструкция, экспорт
- Слева: браузер (порядок микса и библиотека). Ширину и деление между ними можно менять перетаскиванием. В библиотеке есть папки, поиск, сортировка (название, BPM, тональность, лучшее сочетание с выбранным треком…, для всех треков или одной папки) и перестановка перетаскиванием
- В центре: аранжировка (деки A / B, деки C / D для наложенных треков, MIX, сэмплер; дорожку сэмплера можно скрыть)
- Внизу: панель деталей (Ctrl+Alt+I) с вкладками: Обзор, Микс, Трек, Переход, CUE, Луп, FX, Сэмплер, Деки. Развернуть — Ctrl+Alt+F. В полноэкранном окне 16:9 редактор перехода помещается без прокрутки

## Возможности

- Добавление и анализ треков: BPM, сильные доли (Beat This!), структура (интро, дроп… видна и в редакторе CUE), тональность, громкость, жанр (EffNet), подсказки cue от ИИ (CUE-DETR). Импорт из медиатеки iTunes / «Музыки»
- Правка на таймлайне: где и насколько перекрываются треки, склейки, лупы / прыжки, эффекты
- **Смена темпа**: меняйте BPM по ходу микса. Выберите, где начинается смена (после перехода, вместе с ним…) и за сколько тактов (например, вернуть трек с −7,5% к 0,0% за 8 тактов)
- **Наложенные треки (4 деки)**: играть целый трек поверх другого (деки C / D), при желании только вокал или только инструментал. Деки и микшер показывают 4 канала
- **Выход из лупа сведением**: выберите, на каком проходе лупа входит следующий трек
- Редактор перехода: рисуйте линии фейдера, EQ, фильтра, эха, реверберации и вокала / ударных / баса / мелодии. Пресеты, варианты и собственные сохранённые переходы
- Автосведение (шаблоны, варианты, проверка рендером), автоматическая расстановка (включая порядок), инструкция для живого исполнения и треклист для SoundCloud
- Разделение на стемы: вокал, ударные, бас, мелодия (Spleeter 4stems)
- Сэмплер: 8 пэдов (клавиши Q–I), ставятся на доли (запись, роллы, уровень). Встроенные звуки (эйрхорн, даб-сирена, райзеры, импакты, габбер-бочка…) синтезированы специально для DJAW и свободны для миксов, живых сетов и публикаций
- Экспорт: WAV (24 бит) / M4A (AAC 256 кбит/с), 44,1 / 48 кГц, MP4 с визуалом (авто-VJ), живой предпросмотр визуала (Ctrl+Alt+V)
- Сохранение: один файл `.djaw` вместе со звуком (несжатые треки вроде WAV хранятся во FLAC без потерь — примерно вдвое меньше, звук тот же). Последний микс открывается при запуске

Предпросмотр использует тот же движок, что и экспорт: что вы слышите, то и записывается.

Лицензии моделей: `models/ThirdPartyNotices.txt` (EffNet — некоммерческая).
